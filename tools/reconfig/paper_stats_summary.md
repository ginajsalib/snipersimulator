## Discrepancies with the request

1. **`n4_hetero_v2` is the *clamp* tree, not flush.** Its marker reads
   `clamp line=0 dirty=0 dirty_llc=0`. The flush tree with no penalty knobs is
   `n4_hetero_v2flush`, which is what this analysis uses for `dynamic_rf` at
   4c/8c. If the clamp tree was intended instead, rerun with that root — the
   numbers will differ substantially, because clamp refuses almost every shrink.
2. **`n4_hetero_v2flush` contains no `max_resources` arm** (0 of 42 directories).
   Item 6 therefore takes `max_resources` from `n4_hetero_v2` for 4c/8c. This is
   sound: `max_resources` never requests a shrink, so the shrink policy cannot
   affect it, and the clamp-tree run is the same experiment.
3. **The 16-core root is `n4_hetero_v6_16c_flush`** — the tree that produced
   `results_16c_4P12E.csv`. Note it was run with the `simple_prefetcher` `i=0`
   bug reverted, matching the 4c/8c runs.
4. **Commit `87f1c1a` (7 Sep 2026) predates every run** (earliest 4 Oct), so the
   `_new` columns hold post-apply sizes throughout, as assumed.
5. **Configuration definition.** The figures quoted earlier (median 34 distinct,
   1,356 total, top-5 32.6%) came from an uncommitted ad-hoc script that keyed on
   `_req` columns for the caches plus `_new` for BTB/prefetch — a hybrid of
   requested and applied. The committed definition is
   `analyze_final_experiment.config_popularity()`, which keys on **every `_prev`
   column**, i.e. the configuration actually in effect during the interval. This
   analysis uses the committed definition, so the numbers differ from the earlier
   ones by construction.

## Data quality

- All 9,149 decision rows across the 56 runs have status `applied`; none were excluded.
- Every run has exactly one zero-duration McPAT window — the `roi-begin -> 0` window
  emitted before the first interval elapses. It carries weight 0 and does not affect
  any duration-weighted mean.
- Power-window and decision-row counts agree to within 2 in every run (the closing
  ROI-end sample has no decision row).
